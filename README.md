# مترجم آفلاین فارسی ↔ روسی

پروژهٔ جدید برای اجرای کامل زنجیرهٔ گفتار به متن، ترجمه و متن به گفتار بدون ارسال داده به سرویس ابری.

## دامنهٔ MVP

- تشخیص گفتار فارسی و روسی
- ترجمهٔ دوطرفهٔ فارسی ↔ روسی
- تولید صدای فارسی و روسی
- اجرای محلی روی دسکتاپ و آماده‌سازی مسیر اندروید
- ذخیره‌نکردن صوت و متن مگر با درخواست کاربر

## معماری پیشنهادی

```text
Microphone → VAD → STT → Translation → TTS → Speaker
                 ↘ transcript/event log (optional, local only)
```

جزئیات مدل‌ها، معیارهای ارزیابی و مراحل اجرا در [سند معماری](.project-planning/offline-translator-architecture.md) و [نقشهٔ محصول](.project-planning/product-roadmap.md) ثبت شده است.

## وضعیت فعلی

این commit آغاز پروژهٔ جدید است. هنوز مدل‌ها و وابستگی‌های حجیم دانلود نشده‌اند. پیاده‌سازی هر مرحله باید با تست کیفیت و مجوز مدل همراه باشد.

## اصول فنی

- آفلاین‌بودن پیش‌فرض و عدم telemetry
- رابط‌های مستقل برای STT، ترجمه و TTS تا مدل‌ها قابل تعویض باشند
- پشتیبانی از CPU و شتاب‌دهی اختیاری
- آزمون با مجموعهٔ صوتی و جمله‌های فارسی/روسی واقعی
